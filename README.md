
# Calcuneitor 3000

Calcuneitor 3000 is an App made simply for the people who wants to do basic math operations. In it's functions there's basic sum, substraction, multiplication and division modules.


## Technologies

### Lenguajes y Frameworks
* **Flutter:** v3.47.7 (Framework)
* **Dart:** v3.13.4 (programming language)

### Entorno de Desarrollo
* **IDE:** Visual Studio Code v1.143 (w/ official flutter & dart extensions)

## Installation

In the IDE terminal:

```bash
  git clone https://github.com/deerfoster/Calcuneitor-3000.git
```
Look for the project:

```bash
  cd Calcuneitor-3000
```
    
## Deployment

To deploy calcuneitor 3000 you must use Android Studio (include android emulators you prefer/known) or any device with android connected to your unit via USB, other magic tricks don't work (running the app telepathically). 

After those steps, you can run the vscode (include IDE's you prefer/known) terminal and write the command:

```bash
  flutter run
```
It will show the app on screen for you to use.

In there you can press numbers and use the sum, substraction, multiplication and division operationals and the app will show what you need to know.
